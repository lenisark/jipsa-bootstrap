# 부서 위키 / FAQ 문서 폴더

이 폴더에 **사내 문서(규정·절차·자주 묻는 질문 등)** 를 넣어두면,
부서 채널에서 `@집사`에게 물어볼 때 집사가 이 문서들을 근거로 답합니다.

## 사용법
- `.md` 또는 `.txt` 파일로 자유롭게 넣으세요 (예: `휴가규정.md`, `경비처리.md`, `회사-FAQ.md`).
- 파일명은 알아보기 쉽게 — 집사가 질문에 맞는 문서를 찾는 데 도움이 됩니다.
- 내용이 바뀌면 파일만 수정하면 즉시 반영됩니다 (재시작 불필요).
- 민감 정보(개인정보·비밀번호 등)는 넣지 마세요. 부서원 누구나 질문으로 끌어낼 수 있습니다.

## 예시
`회사-FAQ.md` 샘플이 들어있어요. 실제 내용으로 바꿔서 쓰시면 됩니다.
