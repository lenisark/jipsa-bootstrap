# 모듈 11 — 비품관리 (Supply Inventory · jipsa 2.0 P1)

> 전제: 모듈 1·5 완료. 데몬이 돌고 있어야 함.
> 슬랙 비품신청 리스트의 `수령완료` 상태를 집사가 주기적으로 감지해, 구글드라이브 재고 .xlsx를 자동 차감하고 저재고 시 알림을 보낸다.

## 무엇을 하나

비품신청은 슬랙 리스트로 이미 흐른다. 이 모듈을 켜면 집사가 그 리스트를 **5분마다 폴링**해 `수령완료`로 바뀐 신규 항목을 찾고, 해당 품목의 재고를 구글드라이브 엑셀에서 차감한다. 품목명은 자유텍스트라 LLM이 정규화하지만, 결과는 **별칭 캐시**에 기록돼 이후 계산은 완전히 결정적이다.

## 흐름

```
[슬랙 비품신청 리스트]
  ──폴링(lists:read, poll_min분)──▶ 수령완료 && 미처리 항목 감지
                                          │
                              [품목명 정규화 엔진]
                                   ├─ 별칭 캐시 적중 → canonical 즉시 확정
                                   ├─ 미스 + high confidence → LLM 자동 매칭 + 캐시 기록
                                   └─ 미스 + 애매 → 슬랙 확인 요청 + 차감 보류(pending)
                                          │
                              [재고 계산: 결정적 정수 가감]
                                   ├─ 비품재고_현황.xlsx [재고] 시트 차감
                                   ├─ 비품_입출고이력.xlsx 행 추가
                                   └─ 슬랙 알림(차감 완료 / 저재고 경고 / 신규품목)
```

**핵심 불변식:** 재고 수량 계산은 100% 결정적(정수 가감). LLM은 *품목명→canonical* 매칭에만 쓰이고, 그 결과는 별칭 캐시에 저장되어 재실행해도 항상 동일하다.

## 사전 준비

1. **슬랙 앱 스코프** — `lists:read` 추가(추후 상태 되써넣기가 필요하면 `lists:write`도 추가). 스코프 변경 후 앱 재설치 필수.
2. **Python 의존성** — `pip install openpyxl` (xlsx 읽기/쓰기).
3. **구글드라이브 폴더** — `05_총무 영역/비품·고정비/` 폴더가 로컬에 마운트(`G:\공유 드라이브\...`)되어 있어야 함. 두 엑셀 파일은 jipsa가 첫 실행 시 없으면 자동 생성.
4. **초기 재고** — 실사 데이터가 있으면 `비품재고_현황.xlsx` [재고] 시트에 미리 채운다. 없으면 0에서 시작해 신규품목으로 점진 축적해도 된다.

## 설정 (supply.json)

`templates/scripts/slack-jipsa/supply.json.example`을 복사해 `~/.claude/scripts/slack-jipsa/supply.json`으로 배치한 뒤, 아래 값들을 실측값으로 확인·교체한다.

```bash
cp templates/scripts/slack-jipsa/supply.json.example ~/.claude/scripts/slack-jipsa/supply.json
```

주요 필드 설명:

| 필드 | 설명 | 주의 |
|------|------|------|
| `list_id` | 슬랙 비품신청 리스트 ID | `files.info` API로 확인 (`F0AG…`) |
| `poll_min` | 폴링 주기(분) | 기본 5. 너무 짧으면 API 호출 과다 |
| `dry_run` | `true`=실제 차감 없이 예상 결과만 슬랙 게시 | **처음엔 반드시 `true`로 시작** |
| `notify_channel` | 알림을 받을 슬랙 채널 ID | 부서 채널(`C0AG…`) 권장 |
| `folder` | 엑셀 파일이 있는 로컬 경로 | G드라이브 마운트 경로(`G:/공유 드라이브/…`) |
| `stock_xlsx` | 재고 현황 파일명 | `비품재고_현황.xlsx` |
| `ledger_xlsx` | 입출고 이력 파일명 | `비품_입출고이력.xlsx` |
| `cols` | 슬랙 리스트 컬럼 ID 맵 | 리스트 API 응답에서 실측값 그대로 |
| `status_done_option` | '수령완료' 상태 옵션 ID | `OptXGCU61KL` — 변경 시 실측값으로 교체 |
| `categories` | 품목 카테고리 목록 | LLM 정규화 시 어휘 제공용 |
| `managers` | 비품 담당자 슬랙 User ID 목록 | 확인 요청·명령 권한자 |
| `default_min_qty` | 저재고 경고 기본 기준 수량 | 품목별 최소수량 미설정 시 적용 |
| `match_confidence_auto` | 이 수준 이상이면 자동 매칭 | `"high"` 권장. 낮추면 확인 요청 증가 |

## 안전 운영 순서

### 1단계 — dry_run: true 로 1주기 관찰

```json
"dry_run": true
```

데몬 재시작 후 첫 폴링 주기를 기다린다. 슬랙에 `(dry-run) 수령완료 감지: 볼펜 ×3 → 재고 12→9 예상` 형태의 메시지만 게시되며, **실제 엑셀 변경은 없다**. 품목 매칭과 수량 계산이 예상과 맞는지 확인한다.

### 2단계 — dry_run: false 로 실가동

매칭·계산이 올바르면 `supply.json`에서 `dry_run` 값을 `false`로 바꾸고 데몬을 재시작한다.

```json
"dry_run": false
```

### 3단계 — baseline 1회 실행 (최초 1회만)

처음 실가동 시 기존의 `수령완료` 항목들(집사 도입 이전 것)을 **차감 없이** 처리됨으로 등록한다. 이미 실물이 나간 건들이라 재고에서 다시 빼면 이중 차감이 된다. baseline이 끝나면 이후 신규 수령완료 항목부터만 차감이 적용된다.

> baseline은 데몬 첫 실가동에 자동으로 한 번만 수행된다(`supply_state.json`의 `baseline_done` 플래그로 관리). 수동 재실행은 이 플래그를 지우면 된다.

## 품목 확인(pending) 흐름

처음 보는 품목명이 애매해 자동 매칭 신뢰도가 낮으면:

1. 해당 항목의 차감을 **보류(pending)** 상태로 큐에 넣는다.
2. `notify_channel`에 확인 카드 게시: `[이 품목으로 처리][신규 품목으로 등록]` 버튼.
3. 담당자(`managers[]`)가 버튼을 누르면 별칭 캐시에 기록 후 차감 처리.
4. 같은 원문 품목명이 다시 오면 캐시를 적중해 LLM 없이 즉시 결정.

별칭 캐시는 `비품재고_현황.xlsx` [별칭] 시트에 저장된다. 사람이 직접 시트를 편집해 교정할 수도 있다.

## 셋업 순서 (AI가 진행)

1. `supply.json.example` → `supply.json` 복사 후 값 확인.
2. 슬랙 앱에 `lists:read` 스코프 추가 + 앱 재설치.
3. `pip install openpyxl`.
4. `supply.py`·`supply_store.py` 배치:
   ```bash
   cp templates/scripts/slack-jipsa/supply.py ~/.claude/scripts/slack-jipsa/
   cp templates/scripts/slack-jipsa/supply_store.py ~/.claude/scripts/slack-jipsa/
   ```
5. 데몬 재시작.
6. **dry_run: true** 상태로 1주기 관찰 → 매칭·계산 확인.
7. `dry_run: false` 변경 + 데몬 재시작 → 실가동.
8. 채널에서 `재고` 명령으로 현황 조회.

## 슬랙 명령

- `재고` / `재고 {품목}` — 전체 또는 특정 품목 재고 조회 (누구나)
- `비품현황` — 저재고 + 확인대기 요약 (누구나)
- `품목통합 {A} {B}` — 별칭 수동 병합 (담당자)

> 입고(`입고등록`/`입고`) 명령은 P2에서 추가 예정.

## 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 폴링은 되는데 차감이 안 됨 | `dry_run: true` | `supply.json`에서 `false`로 변경 후 재시작 |
| 엑셀 그 주기 건너뜀 | `~$` 임시파일 감지 — 엑셀이 열려 있음 | 엑셀 닫기. 건너뛴 항목은 다음 주기에 재시도 |
| 품목명 불일치 알림이 계속 옴 | 별칭 캐시 미정리 | `비품재고_현황.xlsx` [별칭] 시트에서 원문→canonical 행 추가·정리 |
| 음수 재고 경고 | 실물은 나갔지만 재고가 0이었음 | 경고만, 자동 차단은 하지 않음. `입고`로 재고 보정 |
| `lists:read` 권한 오류 | 스코프 미추가 | 슬랙 앱에 `lists:read` 추가 후 앱 재설치 |
| pending이 쌓이고 처리가 안 됨 | 담당자가 버튼을 못 봄 | `비품현황` 명령으로 미확인 건 수 확인. 주기 알림으로 리마인드 됨 |
