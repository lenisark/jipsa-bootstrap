# 모듈 7 — 부서 공용 집사 (Sonnet · 샌드박스 · 팀 기능)

> 전제: 모듈 1·5 완료. channels.json에 부서 채널 항목이 있어야 함.
> 부서 팀원 여러 명이 함께 쓰는 공용 비서. **Sonnet + 전용폴더 샌드박스 + @멘션 필수 + 읽기/Q&A 전용**으로 안전하게 운영하면서, 알리미·완료체크·투표·위키수집·요약·사내 FAQ를 제공.

## 채널 정책 (보안 핵심)

```json
"C_TEAM_CHANNEL_ID": {
  "label": "부서 공용 비서",
  "model": "sonnet",
  "access": "all",
  "cwd": "~/.claude/scripts/slack-team",
  "add_dirs": [],
  "disallowed_tools": ["Bash", "Write", "Edit", "MultiEdit", "NotebookEdit"],
  "require_mention": true
}
```

- `access: all` — 채널의 **모든 팀원**에게 응답.
- `add_dirs: []` — **샌드박스**. `cwd`(`slack-team/`) 밖은 못 읽고 못 쓴다. 개인 파일·시크릿 보호.
- `disallowed_tools` — Bash/Write/Edit 차단 → **읽기·질문 답변 전용**. 시스템 변경 불가.
- `require_mention: true` — `@집사`로 부를 때만 응답. 팀 잡담에 안 끼어듦.
- `model: sonnet` — 비용·속도 균형 (공용은 호출이 잦음).

## 작업폴더 + 사내 위키/FAQ

`templates/scripts/slack-team/`를 `~/.claude/scripts/slack-team/`로 배치:
- `CLAUDE.md` — 부서 공용 페르소나 + 보안 범위 + "docs/ 문서 근거로 답하라" 규칙.
- `docs/README.md` — 위키/FAQ 폴더 사용법.
- `docs/회사-FAQ.md` — **샘플 골격**. 운영자가 실제 사내 규정으로 채운다.

팀원이 사내 규정·절차를 물으면(`@집사 연차 어떻게 신청해?`) 집사가 `docs/*.md`를 Read 해서 그 근거로 답한다. 근거 없으면 추측 안 하고 "담당부서 확인" 안내. **민감 정보(비밀번호·개인정보)는 docs/에 넣지 말 것** — 누구나 질문으로 끌어낼 수 있음.

## 팀 기능 (daemon.py + reminders.py 내장, 코드 수정 불필요)

| 기능 | 사용법 | 처리 위치 |
|------|--------|-----------|
| ⏰ **알리미** | `@집사 매월 25일 10시에 정산 알려줘` (매월/매주/매일/1회성) | `reminders.py` (정규식 파싱) |
| └ 사전알림 | `… 3일 전에도 알려줘` | |
| └ 담당자 호출 | `… @이름 에게 알려줘` → 알림 시 함께 멘션 | |
| └ 영업일 이동 | 주말·공휴일이면 직전 영업일로 자동 이동 (`holidays` 한국 공휴일) | |
| └ 관리 | `@집사 알림 목록` · `@집사 2번 알림 삭제` · `@집사 2번 알림 16시로 바꿔줘` | |
| ✅ **완료체크** | 알림 메시지에 ✅ 누르면 누가 완료했는지 기록 | `reaction_added` |
| 🗳️ **투표/설문** | `@집사 투표 점심: 김밥 / 국밥 / 파스타` → 이모지 투표 → `@집사 투표 집계` | `polls.json` |
| 📌 **위키수집** | 유용한 메시지에 📌 누르면 집사가 정리해 `docs/위키-수집.md`에 저장 | `reaction_added` |
| 📝 **대화요약** | `@집사 오늘 대화 요약해줘` | 채널 히스토리 |
| 📚 **FAQ** | `@집사 연차 어떻게 신청해?` → `docs/` 근거로 답변 | CLAUDE.md 규칙 |

## 의존성

알리미의 공휴일 이동을 위해 `holidays` 라이브러리 필요:
```
pip install holidays
```
(없어도 데몬은 동작하지만 알리미 모듈이 비활성화됨 — daemon.py가 import 실패를 방어 처리.)

## 셋업 순서 (AI가 진행)

1. **작업폴더 배치** — `templates/scripts/slack-team/`를 `~/.claude/scripts/slack-team/`로 복사 (CLAUDE.md + docs).
2. **FAQ 채우기 안내** — 운영자에게 `docs/회사-FAQ.md`를 실제 사내 내용으로 바꾸도록 안내. 추가 문서(`휴가규정.md` 등)도 자유롭게 넣을 수 있음.
3. **슬랙 스코프/이벤트 확인** — 모듈 5의 부서 스코프(`*:history`, `reactions:*`, `reaction_added` 이벤트)가 적용됐는지 확인. 안 됐으면 추가 후 앱 재설치.
4. **holidays 설치** — `pip install holidays`.
5. **데몬 재시작** — 반영.
6. **온보딩 안내 게시** — 운영자가 원하면 부서 채널에 아래 환영 메시지를 핀(고정)으로 올리도록 안내 (아래 템플릿).
7. **검증** — 부서 채널에서:
   - `@집사 안녕` → 응답 (멘션 없이는 무응답이 정상)
   - `@집사 도움말` → 사용법 안내
   - `@집사 매일 18시에 일일보고 알려줘` → 등록 확인 → `@집사 알림 목록`
   - `@집사 투표 점심: 김밥 / 국밥` → 이모지 → `@집사 투표 집계`
   - 아무 메시지에 📌 → `docs/위키-수집.md`에 저장되는지

## 주의

- 부서 채널은 공용이므로 **누구나 질문으로 docs/ 내용을 끌어낼 수 있다.** 민감 정보는 절대 docs/에 넣지 말 것.
- 샌드박스(`add_dirs: []` + `disallowed_tools`)는 daemon이 `claude` 호출 시 강제하는 안전장치다. channels.json에서 이 값을 비우면 보호가 풀리니 주의.
